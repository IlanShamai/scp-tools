## ✅ Verified accurate

- **Source 1 (Chullin 111b):** Radish + ben-yomo fleishig knife → assur with dairy. Rashi: sharpness + pressure. ✓
- **Source 2 (A.Z. 35b):** Chaltis + eino ben-yomo non-kosher knife → assur. אגב חורפיה מחליא. ✓
- **Machloket A:** Maharam/R"Y = only chaltis; R"B = all sharp foods. ✓
- **Machloket B:** Ra'avad = k'dei netila; Rashba = entire food. ✓
- **S"A:** Follows Maharam + Ra'avad. Eino ben-yomo mutar. Ben-yomo → remove k'dei netila. Shach 5: no tasting l'chatchilla. ✓
- **Rama:** Follows R"B + Rashba. Even eino ben-yomo assur. Entire food l'chatchila. B'dieved: k'dei netila (Shach 10). ✓
- **Shishim calc:** Smaller of blade or k'dei netila. Shach 7. ✓
- **Non-kosher knife:** S"A same rule. Rama: chanan — diced = entire assur; cut once + cook = entire k'dei netila assur. ✓
- **Sharp foods (S"A sif 2):** Garlic, onions, leeks, sour fruits, very salty fish. Like Rambam. B'dieved: צירוף. ✓
- **Yalkut Yosef:** Sephardim follow S"A. Two proofs. ✓
- **Teshuvos V'Hanhagos:** Parve knives. ✓
- **Beis Meir (Ohel Yaakov):** Three opinions combined. Don't rely alone. ✓
- **Pashas (Pnei Me'iros):** Cooking removes sharpness. ✓
- **Er'a'sh §20:** Oil removes sharpness. D't §20 rejects. ✓
- **Cutting board:** Chachmas Adam machmir, Rav Elyashiv lenient (Dvar Charif). Lema'ase lenient. ✓
- **Blender:** Magen Avraham = blender fleishig. Even Ha'ezer = lenient (weakened flavor). Majority lenient. ✓
- **Parve pan:** Stays parve (Even Ha'ezer). Dvar Charif 9:4. ✓
- **Waiting (Dvar Charif 1:10):** No 6 hours. Based on R' Akiva Eiger. ✓
- **Store-cut:** Safek mutar. City where all pre-cut → remove k'dei netila. Taz 8. ✓
- **Leaves:** Not charif. Er'a'sh 17. ✓
